# Plan — WEB-028

- Context:
  The production storefront changes header height and apparent brand scale when users leave the homepage. The logo image and wordmark also sit on different optical baselines, so the lockup reads as two unrelated elements. This is a shared component consistency defect: route color variants may differ, but navigation geometry must remain stable.
- Goals:
  - Capture Home and Shop at identical desktop and mobile viewports and measure the shared header, brand lockup, navigation, and action controls.
  - Establish one shared header geometry contract using the homepage brand scale as the visual target.
  - Align the official logo and wordmark on one optical centerline without replacing either asset.
  - Preserve route navigation, search, account, cart, consent, analytics, accessibility, and the intentional dark/light surface variants.
  - Pass same-viewport design QA and release through the existing AWS Amplify application.
- Risks:
  - Header selectors currently carry route and breakpoint specificity, so a local override can accidentally create a second mobile regression.
  - The logo artwork contains internal transparent space; numeric centering alone may not produce optical alignment.
  - Changing shared header dimensions can shift every storefront route and must be verified beyond Home and Shop.

## Steps
1. Capture and measure the checked-out production Home and Shop header states at matching desktop and mobile viewports; verify the released result separately on the public domain.
2. Trace the shared Header component and all base, dark-variant, and breakpoint selectors to identify the competing geometry rules.
3. Implement one shared height, spacing, brand-lockup, navigation, and action-control contract while retaining color variants.
4. Run local route and responsive checks, create full and focused same-viewport comparisons, and fix all P0-P2 findings.
5. Run repository gates, commit, push, verify the Amplify release and public domain, complete proof/telemetry, and park the slice.
