# Plan — WEB-027

- Context:
  The user selected the brand-led "Quiet Summit" homepage direction after rejecting the current product-led Mako campaign. The existing production hero uses a 1672 px-wide baked image and enlarges the bicycle across larger desktop viewports, which exposes softness and turns the homepage into a single-SKU promotion. The selected design instead frames the bicycle inside a credible rider story and keeps product details out of the permanent brand hero.
- Goals:
  - Produce clean desktop and mobile photographic hero assets from the selected rider-at-summit direction without baked navigation, copy, CTAs, or terrain labels.
  - Keep the bicycle visually coherent, naturally grounded, and recognizable as the mint-and-charcoal Finspeed Mako Shark while avoiding the enlarged cutout treatment.
  - Rebuild the hero as responsive live UI with the selected headline, supporting copy, one primary CTA, and the existing Mountain / City / Hybrid destinations.
  - Preserve storefront routes, consent behavior, analytics, accessibility, and responsive navigation.
  - Pass same-viewport visual QA against the selected reference and release through the existing AWS Amplify application.
- Risks:
  - Generated bicycle mechanics and lettering can drift, so the assets require original-resolution inspection before use.
  - Desktop and mobile crops need separate art direction to keep the rider and bicycle clear without colliding with copy.
  - Large photography can regress performance, so shipped assets require responsive formats and controlled compression.

## Steps
1. Capture the selected visual target and inspect the current production component, breakpoints, tests, and Amplify release contract.
2. Generate and inspect clean desktop and mobile rider-at-summit photographs with protected copy space and no baked UI.
3. Implement the responsive live hero, working CTA, and terrain navigation while removing product price/specification messaging from the homepage hero.
4. Run local browser checks and same-viewport design QA across desktop and mobile; fix all P0-P2 findings.
5. Run repository gates, commit, push, verify the Amplify release and public domain, complete proof/telemetry, and park the slice.
