# Plan — WEB-021

- Context:
  With the core journeys validated, we still need a focused production UAT pass for catalog, model detail, brand story, testimonials, and blog experiences to ensure the full story matches SCN-002, SCN-003, SCN-005, SCN-006, and SCN-007 — and that the UX and aesthetics meet the quality model in `specs/references/handoff/_shared/tests/uat-ux-aesthetics.md`.
- Goals:
  - Confirm riders can browse categories, compare models, read brand/testimonial/blog content, and move between these pages without friction in both languages.
  - Validate that visuals (cards, gradients, typography) and microcopy align with the handoff UI/UX guidance and the brand/aesthetics checklist.
  - Capture artefacts and note any gaps that should be addressed before a public marketing push.
- Risks:
  - Heavy imagery or motion on content pages might regress performance or accessibility budgets.
  - Some catalog/testimonial data may be sample-only; expectations must be calibrated during UAT.

## UAT Scope (per handoff + UX model)
- SCN-002 Catalog:
  - MTB category shows the expected number of models with badges.
  - Filters narrow results without full reload and expose a clear empty state + reset flow.
  - Comparison drawer highlights differences when 2–3 models are selected.
  - UX focus: scan-ability of cards, clarity of filter controls/empty state, comparison drawer readability.
- SCN-003 Model detail:
  - Model pages show hero, specs, sizing guidance, dealer CTA, and JSON-LD that matches catalog data.
  - Dealer CTAs remain usable when locator is under outage (non-blocking banner with alternate support).
  - UX focus: clarity of specs/sizing sections, CTA prominence, outage messaging.
- SCN-005 Brand story:
  - Brand story page renders “Turning Pedals into Power” narrative with bilingual mission/timeline and working CTAs (“Explore catalog”, “Find a dealer”).
  - UX focus: storytelling flow, visual hierarchy, readability on mobile.
- SCN-006 Testimonials:
  - Testimonials grid/carousel shows rider quotes, attributions, and CTAs; interaction is keyboard-friendly.
  - UX focus: carousel discoverability, quote readability, CTA clarity.
- SCN-007 Blog:
  - Blog landing lists posts with categories/dates; article view renders content with correct typography and footer links.
  - UX focus: content density, article readability, navigation between posts and back to catalog/support.

## Steps
1. **Scenario inventory** — Map each SCN acceptance feature to concrete production URLs (catalog, model detail slugs, brand story, testimonials, blog) and list the exact flows to exercise, including UX checks from `uat-ux-aesthetics.md`.
2. **Headed walkthroughs** — Using a headed browser (manual or Playwright-driven), run through each scenario in EN and HI, capturing screenshots for key states (catalog with filters, comparison drawer, representative model pages, brand story hero, testimonials view, blog article); rate UX and aesthetics (1–5) per journey.
3. **Accessibility & performance spot checks** — For catalog, model detail, and brand story, run quick axe or Playwright a11y checks plus 1–2 Lighthouse snapshots to confirm there are no obvious regressions against NFR-002 budgets and that basic keyboard navigation feels solid.
4. **Narrative & UX review** — Evaluate whether copy, layout, and CTAs tell a coherent story from catalog → model detail → dealer/support; note any confusing transitions, missing links, or localisation gaps.
5. **Proof & issues log** — Record findings and RESULT in `specs/proofs/web/WEB-021/README.md`, attach artefacts, and open follow-up slices for issues that should block launch, tagging them as Functional/Usability/Visual/Content with P0–P3 severity per the UX model.
