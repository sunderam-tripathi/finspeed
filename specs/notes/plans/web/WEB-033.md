# Plan — WEB-033

## Context

The App Router still ships the default Next.js/Vercel triangle in `src/app/favicon.ico`. The production tab therefore does not carry Finspeed brand recognition even though official square logo marks already exist in the app.

## Goal

Replace only the framework favicon with a crisp, contrast-safe browser icon derived from the official Finspeed mark, then release and verify it without changing page layout or other brand assets.

## Risks

- Fine wordmark details become illegible at 16 px, so the favicon must use the emblem rather than the full lockup.
- A transparent white emblem can disappear in light browser chrome, so the derived asset needs a stable dark field.
- Browser caching can mask the new icon; production verification must compare the served bytes and inspect the document icon link.

## Steps

1. Inspect the current favicon and official logo assets at full and favicon scale.
2. Generate a multi-resolution ICO plus application icon files from the official light mark.
3. Verify metadata, image dimensions, lint, production build, and local browser rendering.
4. Commit and deploy through the existing AWS Amplify production application.
5. Verify the public icon response, document link, browser console, and production release evidence.
