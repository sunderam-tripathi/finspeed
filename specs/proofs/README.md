# Proof Assembly Expectations

For each slice under `specs/proofs/<domain>/<SLICE-ID>/` include:
- README.md with steps and RESULT markers.
- Parity logs and production evidence (where applicable).
- Linked artefacts (screenshots, logs, exports).
- Screenshot validation is visual: open each capture and zoom in to confirm the content matches the scenario (not just file size/dimensions). Record the check in the proof README alongside the artefact link.
