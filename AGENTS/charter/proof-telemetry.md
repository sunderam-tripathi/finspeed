# Proof & Telemetry Contracts

Required artefacts per slice:
- README describing verification steps and results.
- Evidence from parity environment and (if possible) production.
- RESULT markers in README summarizing pass/fail.
- Attach logs/screenshots under the slice directory.

Telemetry commands:
- `npm run spec:slice-index` generates `specs/notes/indexes/slice-index.md`.
- `npm run spec:progress` updates `specs/project-progress/progress-summary.json`.
