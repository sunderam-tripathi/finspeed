# Slice Supplement — WEB-028

Title: Consistent storefront header geometry
Domain: web

Scope:
- Normalize the shared storefront header so its height, logo lockup, navigation, and action controls do not change scale or alignment between routes.
- Preserve the existing official Finspeed logo asset and current route-specific dark/light color treatment.

- Preserve all existing header navigation, search, account, cart, consent, and analytics behavior.

Notes:

- The fix must be shared-component/token driven rather than route-specific positional patches.
